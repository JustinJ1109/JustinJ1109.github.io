Tutorial: Download the Modpack

Step 0: Create a profile in Curseforge (This step can be skipped if you already downloaded the previous pack, in which case you would use the existing mod pack profile)

Ensure that Minecraft version is set to 1.19.2, game type is set to Forge, and modloader version is forge-43.5.0

Step 1: Download the modpack

The zip files are provided at this google drive link

Step 2: Open the source folder for the Curseforge modpack

Step 3: Copy the `mod` and `config` files to overwrite the existing files

Say "yes", "yes to all", or "replace" if prompted to overwrite existing files

If you navigate back to Curseforge, you should see that all mods are now populated.
